# 检索路由

这是一份方法表，不是当前菜单、数据量或账户权限清单。入口可能迁移；从相应官方网站确认当前路径，不遍历猜测的接口。题设明确指定平台时，辅助来源只用于发现、交叉核对或明确标记的候选。

| 任务 | 优先路径 | 决定答案前核对 |
|---|---|---|
| 文献组合检索、统计 | 指定库的高级检索和结果分析 | 子库、字段、括号、精确/模糊、扩展、年份、实际表达式与结果样本 |
| CNKI 文献、机构/作者排名 | [CNKI](https://www.cnki.net/) 当前检索与分析页 | 主题相关匹配不等于精确词匹配；作者、第一作者、作者单位、第一单位、授予单位分开。专业式与高级表单只有语义确认等价才能互证 |
| 万方期刊/学位/会议 | [万方](https://www.wanfangdata.com.cn/) 对应子库 | 默认可能同时选多个子库；切换会改变条件。核学位年/发表年、同义词/中英文扩展和返回的文献类型 |
| 维普期刊、来源与主题分析 | [维普期刊](https://qikan.cqvip.com/) | 篇名/摘要/关键词分开，来源目录版本、年份和统计范围都要明确；人物主页的研究方向不等于本次结果分析的“主要主题” |
| CNKIAI、AI知数、研学、图片库 | 从知网官网或用户已授权产品入口进入 | 文献 MCP 不证明产品界面能力；研学/书馆/KNS 等不同产品的字段不可拼成一份菜单 |
| 生成研究与引文核验 | [LeapSpace](https://www.sciencedirect.com/leapspace/) 或题设指定产品 | 找到本次输出；引用卡、论断核验、综合研究、写作辅助按当前入口区分，支持标签不代替原文 |
| 文献日期、作者、类型 | 出版者记录、DOI 对应原文、指定库题录 | 登记创建日、在线发表日、卷期日不同；会议摘要、会议论文、期刊论文、学位论文分别核验 |
| PDF 页数、某页内容、图型 | 原站公开原件或用户合法取得的文件 | 题名、作者、年份、版本；文件总页数/印刷页码/整页续文；视觉类别与数据库分类标签分开 |
| 专利及同族 | 题设指定专利系统及原始公开文本 | 申请号/公开号、文献类型后缀、日期字段、同族定义；文献行数不是发明件数 |
| 标准、法律、官方登记记录 | 对应主管机构的公开查询 | 全部标准/国家标准子集、现行/废止、强制/推荐；机构完整名称、有效状态及查询时点 |
| 馆藏、书籍版本 | 指定馆藏目录、图书平台 | ISBN/作者/版次/出版年/卷册/记录号；整书与章节检索字段、馆藏与可借分开 |
| 年鉴、数据表、指数 | 原统计表或指定指数平台 | 地区、年份、单位、累计/当期、现价/不变价、指标定义；AI生成解释不代替数值来源 |
| 产品菜单与免费权限 | 指定端、版本、账号的实际子入口 | 输入/输出、语言识别/翻译目标、可见/可启用/可保存、免费/试用/付费逐项区分 |
| Office、引用格式、插件 | 指定版本的官方文档；需要时低成本实操 | 系统和端、函数匹配模式、标准版本、插件与内置能力；不为一道题自动安装软件 |
| 给定集合逻辑或表格计算 | 本地推理/计算 | 题设数据齐全、单位与边界条件一致，不为形式完整而外部搜索 |

## 自然语言条件到实际查询

先把条件写成与平台语法无关的结构：

> 子库＝学位论文；题名包含甲或乙，且不包含丙；授予年度在指定区间；按授予单位统计。

再映射到当前页面字段与运算符，不把别家系统的 `*`、`%`、引号或括号直接搬过来。精确/模糊是具体字段的匹配规则，不是通用开关。高级检索和专业式交叉验证时，同样核对扩展与样本，而不只比较总数。

切换库或检索模式后先回读条件再提交。正常输入、候选选择和失焦可能都是表单接受条件的必要步骤；只读日期框用其正常日历。不能直接改 DOM 值或调用未公开接口冒充正常检索。

对“最接近”的数量题分别记实际结果与选项值；只在题干允许近似时比较距离。要求确切数字但没有精确匹配时保留差异，不能为贴选项改条件，也不能无证据归因于数据库更新。

维护、缺失历史版本、无权限或无可靠原件是不同阻塞。尝试替代路径前说明它与失败路径有何实质区别；反复刷新和改写同一关键词不是新路径。
