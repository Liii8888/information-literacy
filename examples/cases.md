# 合成案例

以下均为教学用合成题面与观察，不来自实际试卷，也不是线上平台当前事实。用来解释决策，不作为已完成的独立能力测试或答案库。

## 1. 年份变化后旧题不再命中

旧资料是“学位授予年度2020—2022，题名包含甲或乙”；新题是“上网年度2023—2024，题名包含甲且不含乙”。

应重新映射日期字段与逻辑并执行查询。即使对象和选项相似，也不能复用旧数字。新结果可能碰巧相同，不能为了证明题不同而强求不同答案。

## 2. 改了输入，结果仍旧

在同一会话把地区A换成地区B，输入框已显示B，但结果标题仍写A。不能提交A的数量，也不能认定B没有结果。正常提交/失焦后读取生效条件及结果身份；仍失败则记录操作缺口，不绕过页面直接改后台状态。

## 3. 并列与多选映射

题面给出的完整统计表为：甲12、乙10、丙10、丁8。问“数量处于前两个不同档位的机构有哪些？”选项顺序为A丁、B丙、C甲、D乙。

由题面可直接求得甲、乙、丙，当前映射为BCD。若问题改成“前两条记录”，应先确认并列排序规则；不能沿用同一解释。无需外部检索，也不能拿旧题的字母代替文字映射。

## 4. 功能可见但免费账户无法保存

合成观察：真实免费账户的下拉框列出1—5，选3后出现升级提示，保存并刷新回到1。题问“该账户可以保存3项吗？”

实际观察支持不能。若只是读到帮助页“支持1—5”，只能支持产品存在此能力，不能说免费账户实际通过。修改与保存只在获准测试对象上执行。

## 5. 引文只有相近主题

题目论断限定“室温、悬空样品、相较体相”。生成工具给出若干支持引文，其中一篇只研究低温基底样品。

这篇不能独立证明题目完整论断；保留限定继续查关键原文。支持数量不修补条件缺失，标签也不等于结论。

## 6. 不可返回与汇总判分

场次明确逐题提交、不可返回。证据仍不足时必须在本题预算与规则内决定，不能计划答完再补。假设最终汇总显示多选全部判对、单选有错，只能把错题范围收缩到单选；不能因为某道多选当时猜选就认定它造成失分。
