# AI+信息素养淘汰赛 Skill

**给 Agent 使用的淘汰赛赛前 Chat 初始化 Skill。** Agent 负责打开普通网页版 Chat、设置模式、发送初始化全文并核对就绪状态；准备完成后，选手在该 Chat 中逐题发送完整截图，获得**唯一推荐答案＋一句判据**，自行判断和填答。

**选用配置：DeepSeek 网页版普通对话，开启“深度思考”和“联网搜索”**（下述实测时界面称“智能搜索”）。不指定未经确认的后台模型版本。

这是独立的 `information-literacy-knockout` Skill。仓库根目录的初赛版 `information-literacy` 保持不变。

## 为什么单独做淘汰赛版

本版按淘汰赛不使用赛事专用答题 Agent 和自动化检索工作流的边界设计，因此**不把初赛 Skill 的 Agent 答题流程直接搬到淘汰赛中使用**。初赛版让 Agent 执行检索、证据核对和作答；本版让 Agent 在赛前初始化一个普通网页版 Chat，赛中由选手手动调用该 Chat。

分工为：**Agent 加载本 Skill → 赛前初始化网页 Chat → 交给选手手动发题 → 普通 Chat 回答 → 选手判断与填答**。Skill 是供 Agent 执行准备工作的组织形式，不是让 Agent 在赛中代答。具体场次仍以当场工具规则为准。

初始化全文针对淘汰赛的短时限、完整截图输入、两行输出和缺证收尾进行整理，分别准备个人赛与团队赛入口。

## 直接开始

1. 把完整 Skill 文件夹提供给有浏览器操作能力的 Agent，并说明要准备个人赛、团队赛或两个 Chat。
2. Agent 按 [初始化 SOP](references/initialization-sop.md) 打开 DeepSeek 网页版，开启深度思考和联网搜索，发送对应的 [个人赛全文](assets/personal-chat-init.txt) 或 [团队赛全文](assets/team-chat-init.txt)。登录和验证码由使用者完成。
3. Agent 核对网页中实际发送的全文、实际收到的“准备好了”、两个开关及零题状态，交付可继续使用的聊天入口。只要求初始化时不发送测试题；需要链路试跑时另按用户要求执行。
4. 选手接手后，在普通 Chat 中手动发送完整题图、阅读回复并自行填答；Agent 不接管赛中题目流转或答题页面。

个人模板沿用 P1，训练设置为 10 题、5 分钟；团队模板沿用 G1T，训练设置为 10 题、15 分钟。实际规则、模型和档位由使用者核实，可在初始化前调整。模板不绑定某一产品或模型，也不代表已验证所有宿主的效果。

## 给 Agent 使用

按 Agent 宿主的技能目录约定放置**整个 `information-literacy-knockout` 文件夹**，保留 `assets` 和 `references`。只复制 `SKILL.md` 会缺少初始化全文和 SOP。Skill 装在准备工作的 Agent 一侧，不要求目标网页 Chat 支持原生 Skill。

支持技能调用的宿主可输入：

> 使用 $information-literacy-knockout，在赛前帮我初始化一个淘汰赛个人赛 DeepSeek 网页版 Chat，开启深度思考和联网搜索，发送个人赛全文并核验零题就绪；不要开始答题。

已有同名 Skill 时先比较版本，再由使用者决定替换或另存。仅下载、安装或出现技能标签，不能证明本轮已加载全文。

Agent 没有浏览器操作能力时，只能交付初始化全文和人工步骤，不能宣称网页 Chat 已初始化。使用者也可以自行按 SOP 完成相同准备。

模拟 3 的参考计分为单选 13×2＋多选 10×2.5＋判断 7＝58；参考键存在原件版本及现行规则冲突，不能据此声称真实正确率为 60%。模拟 2 的 39 题中另有两道口径争议，排除后为 **32/37**；其余 11 题始终保留为未判定，没有算成答对。

模拟 2 此前 D0.14 为 31/39；D0.34 是非同期的已见卷重复测试，初始化含赛前资料卡。该卷输入为官方归档题干和选项重绘的 PNG，不是原考试界面截图。两轮不能作为陌生题提升或纯模型能力对比。D0.xx 是测试提示词编号，**与本包 P1／G1T 模板不同，这些结果不代表本包已经取得相同分数**。也未完成选手本人 5 分钟或 15 分钟的全流程验收。
