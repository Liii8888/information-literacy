# AI+信息素养淘汰赛 Skill

淘汰赛的对话初始化、截图辅助和限时练习流程。准备好个人赛或团队赛对话后，选手逐题发送完整截图，得到**唯一推荐答案＋一句判据**，自行判断和填答。

这是独立的 `information-literacy-knockout` Skill。仓库根目录的初赛版 `information-literacy` 保持不变。

## 直接开始

1. 按 [初始化 SOP](references/initialization-sop.md) 选择本轮模型、环节与时限。
2. 在准备好的聊天窗口，一次性发送 [个人赛初始化全文](assets/personal-chat-init.txt) 或 [团队赛初始化全文](assets/team-chat-init.txt)。复制文件的全部内容，不只发文件名或版本号。
3. 收到“准备好了”后，核对正文和模型档位；按 SOP 完成必要的赛前链路测试。
4. 开始练习时，只发送完整题目截图。缺证会标“不确定”，不会把估计写成已经查到。

个人模板沿用 P1，训练设置为 10 题、5 分钟；团队模板沿用 G1T，训练设置为 10 题、15 分钟。实际规则、模型和档位由使用者核实，可在初始化前调整。模板不绑定某一产品或模型，也不代表已验证所有宿主的效果。

## 作为 Skill 使用

按宿主的技能目录约定放置**整个 `information-literacy-knockout` 文件夹**，保留 `assets` 和 `references`。只复制 `SKILL.md` 会缺少初始化全文和 SOP。不支持原生 Skill 的普通聊天，直接使用上面的全文即可。

支持技能调用的宿主可输入：

> 使用 $information-literacy-knockout，帮我准备淘汰赛个人模拟练习对话，按初始化 SOP 检查就绪状态。

已有同名 Skill 时先比较版本，再由使用者决定替换或另存。仅下载、安装或出现技能标签，不能证明本轮已加载全文。
