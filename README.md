# information-literacy

**面向 Agent 的信息检索与证据核验 Skill。** 用于信息素养练习、资料查询，以及规则明确允许并由用户授权的辅助答题。

采用 [MIT 许可](LICENSE)。包内没有私人题库、真实试卷、成绩记录、账号、认证会话或第三方全文。

## 能做什么

- 把自然语言题设转换为库、字段、逻辑、时间和匹配条件。
- 核对真实查询是否生效，避免旧结果、漏条件、分页和并列造成误答。
- 区分原始文件、图像和具体产品入口；把“功能存在”与“本账户可用”分开。
- 保留事实证据、作答候选和评分支持的不同状态。
- 按当前选项文字选择，并在有授权时核对真实选中状态。
- 遇到认证时清晰交接，恢复后继续原任务。

它不提供数据库权限、浏览器实现、题库命中服务或满分保证，也不自动取得正式考试授权。没有浏览器的执行者可以分析公开文档，但不能宣称完成了登录后菜单或表单实操。

## 使用

整个 `information-literacy` 文件夹就是一个 Skill，`SKILL.md` 是入口，其他文件是按需读取的配套内容，不能只复制入口文件。

在支持目录式 Skill 的宿主中，按该宿主说明把**整个文件夹**放入它的技能目录并启用。这里不运行安装脚本、不改全局配置，不假定所有宿主的安装位置相同。不支持自动发现时，可直接让 Agent 读取该目录的 `SKILL.md`，并提供目录读取权限。

调用示例：

> 使用 information-literacy 处理下面这道题。当前任务是备赛练习；使用现有浏览器和检索资源，不提交任何考试。题型：……，完整题干：……，选项：……。

若宿主支持 `$技能名`，也可用 `$information-literacy` 调用。图片题需要提供清晰图像或可访问页面；不要提供密码、验证码或会话凭据。

默认返回“答案、关键依据、置信度、来源”。批量限时作答还需说明计时、能否返回、计分方式、可用工具及最终提交权限。

## 运行条件

| 工作 | 所需宿主能力 |
|---|---|
| 给定材料推理 | 能读取完整题面、必要图像 |
| 公开资料查证 | 搜索或公开网页读取 |
| 登录后的表单/菜单实操 | 当前执行者可控制的浏览器，以及用户合法权限 |
| PDF原件核验 | 获准文件读取、现有PDF解析或渲染能力 |

这些能力由宿主提供，本包没有 MCP、Python或浏览器插件等代码依赖。优先使用用户指定浏览器与已有工具；缺能力就说明具体影响，不擅自安装替代品。认证由用户完成。

## 独立性与验证边界

本包从实际检索与练习中提炼方法，没有复制原项目依赖私人记录的查题脚本。完整新题应独立求解，缺题库不构成阻塞；使用者可另行接入自己有权使用的资料，但不是本包的运行条件。

发布前检查入口格式、相对链接、文件清单、打包内容和个人信息/会话痕迹。这些是结构与发布卫生检查，不证明实时网站可用、所有产品都验证过或新题必然答对。此包尚未作为独立安装包完成跨宿主现场验收。

## 维护

报告问题时优先提供脱敏或自编的最小题面、平台/版本、实际操作与证据缺口，不提交有访问限制的真实试卷、评分键、认证链接或私人文件。菜单与语法变化应更新方法和适用条件，不增加永久答案数字。工具具备的能力与文档声称的能力须分别说明。

产品名称仅用于说明适用路径，本项目不是相关平台或赛事的官方产品。MIT许可只覆盖本包中可授权的原创内容，不授予链接网站、数据库、论文或产品素材的再分发权。
